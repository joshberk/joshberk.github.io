# Joshua Berkoh's Personal Website

This is the source code for my personal website and blog, built with Jekyll and hosted on GitHub Pages. The site serves as a portfolio for my work as a PhD student in Information Technology, and showcases my skills, research interests, and blog posts on cryptography and cybersecurity.

## Features

*   **Jekyll:** A static site generator that is well-suited for this type of project.
*   **GitHub Pages:** A free and reliable hosting service for static websites.
*   **Custom Theme:** A fully custom professional design built with SCSS — no external Jekyll theme.
*   **SCSS:** CSS variables, light/dark mode theming, and responsive layouts.
*   **JavaScript:** Used to add interactive features like a theme toggle, terminal effects, and smooth scrolling.

## Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites

*   Ruby
*   Bundler
*   Jekyll

### Installation

1.  Clone the repo
    ```sh
    git clone https://github.com/joshberk/joshberk.github.io.git
    ```
2.  Install dependencies
    ```sh
    bundle install
    ```
3.  Run the development server
    ```sh
    bundle exec jekyll serve
    ```
